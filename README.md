## Архитектура

Библиотека использует системный API `SCNetworkReachability` для отслеживания изменений сетевой доступности.

Основная последовательность обработки событий:

1. `Reachability.startNotifier()` регистрирует системный callback.
2. При изменении сети callback обновляет свойство `flags`.
3. Наблюдатель `didSet` проверяет изменение флагов.
4. `notifyReachabilityChanged()` организует доставку события.
5. Приложение получает уведомление через closures или `NotificationCenter`.

В исследовании рассматриваются класс `Reachability`, вспомогательный `ReachabilityWeakifier`, системные зависимости и реализация Observer-подобного механизма уведомлений.

## Демонстрационный проект

Приложение предназначено для демонстрации работы исследуемого механизма.

С его помощью можно наблюдать изменения сетевой доступности и проследить распространение событий от системного API до приложения.

## Запуск

1. Клонировать репозиторий.
2. Открыть проект в Xcode.
3. Дождаться загрузки Swift Package Dependencies.
4. Убедиться, что используется Reachability.swift версии `5.2.4`.
5. Собрать и запустить приложение на iPhone или в iOS Simulator.
6. Изменять состояние сетевого подключения для наблюдения событий.

## Отладка механизма

Для изучения внутренней архитектуры можно установить breakpoint'ы в следующих местах исходного кода Reachability.swift:

- `startNotifier()` — регистрация системного callback.
- `flags.didSet` — проверка изменения флагов.
- `notifyReachabilityChanged()` — распространение события.

Это позволяет проследить взаимодействие компонентов библиотеки во время выполнения приложения.
